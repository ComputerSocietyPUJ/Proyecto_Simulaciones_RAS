# Computer society 
Este repositorio tiene la finalidad de hacer que se entiendan los diferentes conceptos aplicados en computer society, de tal manera que se hagan la implementación de simulaciones las cuales nos permitan tener una visualización más dinámica mediante una página web.

## Proyectos
Los proyecto presentados a continuación se dan de tal manera que hacen una muestra de los diferentes elementos asignados.

### Proyecto simulación RAS
Este proyecto tiene la finalidad de hacer la simulación de componenetes electrónicos, de tal manera que podamos hacer una impementación mediante el navegador y teniendo en cuenta que se hace una implementación mediante *localhost* de tal manera que podamos generar una visualización local.
